PARTYZRA PHOTOGRAPHY — OPTION A RED GRID ENERGY

Replace:
  css/photography.css
  js/photography-page.js

EFFECT
- Keeps the existing black grid gutters.
- Adds at most one subtle horizontal red pulse and one subtle vertical pulse.
- Pulses are short, soft-ended dark-red streaks rather than full neon lines.
- They move ONLY through measured gaps between photographs.
- They pause for several seconds between passes.
- Each pass chooses a different real gutter/row when possible.
- No photograph is tinted, covered, or modified.
- Album switching re-measures the new grid automatically.
- Responsive layouts are measured from the actual DOM, so 3-column / 2-column /
  1-column layouts remain safe.
- On a one-column layout, the vertical effect naturally disappears because
  there is no vertical photo gutter.
- Reduced-motion users do not receive the animated effect.

This is intentionally the restrained / liminal version.
