Analytics & privacy.

This independently hosted portfolio uses a custom Cloudflare Worker and Cloudflare D1 database to understand which pages, albums, and photographs visitors explore.

Basic site measurements

Ordinary page and photo interactions may be recorded using temporary session identifiers, event times, page names, image filenames, album selections, and referring websites where supplied. These events help measure engagement. They are not intended to identify people.

Optional returning-browser measurement

If you select Allow in the browser notice, the site generates a random first-party identifier and saves it in your browser's local storage. It sends that identifier with future analytics events, allowing multiple browsing sessions from the same browser to be grouped. No long-term browser identifier is generated before you opt in.

Recognition is only for this browser profile and is not reliable across other browsers or devices. This is pseudonymous tracking, not personal identification. No advertising profiles are created or shared with advertisers.

Your controls

Use Privacy in the bottom-left of the public site to allow or stop optional returning-browser recognition. Stopping removes the identifier from that browser so future events will not be associated with it. Already recorded events remain in the database; stopping alone does not erase prior records.

You can also disable site analytics in this browser, or turn basic analytics back on. These preferences are browser-specific and can be reset when browser storage is cleared.

Data handling

The custom analytics events intentionally do not store IP addresses, precise locations, names, emails, or browser fingerprints. Requests reach Cloudflare, which processes connection data as part of delivering the service. The site owner may exclude personal public IPs at the Worker before events are written. Analytics records are retained for historical engagement comparisons; no automatic deletion schedule is currently configured.

Because consent and privacy rules vary by location, this notice is explanatory and not a complete legal determination of every requirement. You can contact the site owner through the contact information displayed on the portfolio to discuss privacy questions or data requests.
