PARTYZRA PHOTO SHARE LINKS

Replace these two files in your repo:
  js/photos.js
  js/photography-page.js

FEATURES
- Direct links use photography.html#slug
- Example added: photography.html#seagulls
- Opening a direct link automatically opens that photo fullscreen.
- Next/Previous does NOT keep changing the URL.
- If someone arrived via a #slug and then browses to another photo, the hash is removed once.
- Closing a directly linked photo also returns the URL to photography.html.
- COPY LINK in the viewer copies the current photo link without changing the address bar.
- Every photo gets an automatic filename-based fallback slug.
- Add an explicit field such as "slug": "seagulls" when you want a cleaner/stable public link.

No HTML or CSS files need to change.
