MEDIA PROTECTION UPDATE

Added js/media-protection.js and loaded it on the portfolio content pages.

What it does:
- Blocks right-click context menus on portfolio photos, hero imagery, and videos.
- Blocks dragging images/videos out of the browser.
- Disables iOS/WebKit long-press media callouts where supported.
- Adds "nodownload" / remote-playback restrictions to HTML video elements.
- Automatically applies to gallery images created dynamically by JavaScript.

Important:
This is a deterrent, not DRM. A browser must receive an image/video in order to
show it, so a determined visitor can still recover a delivered file using browser
developer tools, network inspection, cache access, or screenshots/screen recording.

Best protection for a photography portfolio:
Do not publish camera originals/master video files. Publish web-display versions
instead and keep true originals/masters private.
